# Tools & External Resources

Curated links for people building things with or around the mesh. This page is intentionally focused on tools, documentation, and reference material — for how to reach our community, see **[Matrix Server & Community](?section=matrix-and-community)**.

---

## Official protocol resources

### MeshCore
- **[MeshCore GitHub](https://github.com/meshcore-dev/MeshCore)** — source code, issues, release notes
- **[Web flasher](https://flasher.meshcore.co.uk)** — flash firmware from a Chromium browser
- **[Web config tool](https://config.meshcore.dev)** — configure Repeaters and Room Servers from a browser
- **[MeshCore app](https://meshcore.co.uk)** — iOS and Android Companion app
- **[LetsMesh analyzer](https://analyzer.letsmesh.net)** — packet-level analysis, regional packet feeds

### Meshtastic
- **[Meshtastic official site](https://meshtastic.org)** — project homepage, docs
- **[Firmware releases](https://github.com/meshtastic/firmware/releases)** — GitHub release page
- **[MQTT docs](https://meshtastic.org/docs/configuration/module/mqtt/)** — official MQTT integration spec
- **[Meshtastic Flasher](https://flasher.meshtastic.org)** — web-based firmware flasher
- **[Meshtastic Discord](https://meshtastic.org/discord)** — upstream community

## RF and antenna reference

For when you want to go deeper into the radio side:

- **[ARRL Antenna Book](https://www.arrl.org/arrl-antenna-book)** — the standard reference for amateur RF work. Applies directly to LoRa antenna design
- **[Fresnel Zone Calculator](https://www.qsl.net/n1bwt/fresnel.html)** — plan line-of-sight paths with vegetation / terrain clearance
- **[LMR coax loss calculator](https://timesmicrowave.com/calculator/)** — Times Microwave's official LMR-series loss calculator

## LoRa basics

If you're new to the underlying technology:

- **[Semtech LoRa intro](https://www.semtech.com/lora)** — the chip manufacturer's explanation
- **[Liam Cottle's "Getting Started with Meshtastic"](https://blog.liamcottle.com/2024/05/01/getting-started-with-meshtastic)** — independent introduction, still relevant to MeshCore users
- **[Meshtastic networking concepts](https://meshtastic.org/docs/overview/mesh-algo/)** — explains flooding and hop limits
