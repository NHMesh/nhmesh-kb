# NH Cheat Sheet

One page of the values you need to get on the NHMesh network. Skim it on your phone in the field. For the reasoning, follow the links.

## Radio

| Protocol | Setting | Value |
|---|---|---|
| **MeshCore** | Preset | US Recommended |
| **MeshCore** | Frequency / bandwidth / SF / CR | `910.525` MHz, `62.5` kHz, SF `7`, CR `5` |
| **MeshCore** | Firmware | US 915 MHz variant |
| **Meshtastic** | Region | `US` |
| **Meshtastic** | Preset | `LongFast` (MediumFast is supported, not recommended) |

Details: **[MeshCore Node Setup](?section=meshcore-setup)** and **[Meshtastic Node Setup](?section=meshtastic-setup)**.

## Channels (MeshCore)

| Channel | Use |
|---|---|
| `#nhmesh` | General chat and questions |
| `#nh-hc` | Health checks and radio tests (the name the Health Check page tells you to send to) |
| Public | Only when you need to reach everyone. It floods; use it sparingly |

Rules of thumb: **[Stewardship & Hashtag Channels](?section=meshcore-hashtag-channels)**. Hashtag channels are not private.

## Quick checks

- On the map? Open [nhmesh.live](/).
- Who hears me? Use the **[Health Check](?section=health-check)**.
- Is an observer down? [nhmesh.live/observers](/observers).
- Node not showing? **[MeshCore Troubleshooting](?section=meshcore-troubleshooting)**.
